1:39   └ eghis에서 처방 통계 엑셀 받기

3:19 3. 주문 → 입고 (카톡 주문서)
4:28 4. 입고 체크와 미송
5:26 5. 향정 하루 사용량
6:12 6. 재고 다시 맞추기 (통 + 낱알)
